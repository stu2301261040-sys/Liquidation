# UniversityStudentsProject

Конзолно C# приложение, реализиращо условието чрез:
- Singleton – University
- Factory – ProgramFactory
- Decorator – ProgramDecorator, TeamworkDecorator, SoloDecorator
- Strategy – IExecutionStrategy и трите места за изпълнение

Стартиране:
1. Отвори `UniversityStudentsProject.csproj` във Visual Studio.
2. Build Solution.
3. Run (Ctrl+F5).
